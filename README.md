# SAHARA

Street Animal Help & Rescue Application, with a proposed Pune and PCMC pilot.

This repository currently contains the implementation plan. Application development, service integrations, and deployment remain planned work.

- [Implementation plan](plan.md): architecture, database design, workflows, API contracts, roadmap, and acceptance checks.
- [PDF edition](output/pdf/SAHARA-Implementation-Plan.pdf): the complete plan with a linked contents page and section bookmarks.

The earlier standalone PawAlert prototype was reviewed and removed at the project owner's request, as recorded in the plan. Its original commit remains in Git history.

The first implementation milestone is one persistent live-trauma reporting flow through unique rescuer acceptance and proof-gated closure across separate sessions. See the plan for the proposed stack and setup sequence; application build and test commands are not available yet.

Temporary PDF dependencies and preview images under `tmp/` are excluded from version control.
